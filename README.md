# SLG Furniture React Website

## Run locally
1. Run `npm install`.
2. Run `npm run dev`.

## Production build
Run `npm run build`.

## Structure
- `src/App.jsx`: app routes
- `src/components/Navbar.jsx`: navbar component
- `src/components/Navbar.css`: responsive navbar styles
- `src/pages/Home.jsx`: homepage sections and page data (no data.js)
- `src/pages/Home.css`: homepage layout and responsive styles
- `src/index.css`: global styles
- `src/main.jsx`: React entry point
- `vite.config.js`: Vite React configuration
