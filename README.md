# SLG Furniture React Website

## Run locally
1. Extract this ZIP and open the folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Production build
Run `npm run build`.

## Structure
- `src/App.jsx`: app routes
- `src/components/Navbar.jsx`: navbar component
- `src/components/Navbar.css`: responsive navbar styles
- `src/pages/Home.jsx`: homepage sections and page data (no data.js)
- `src/pages/Home.css`: homepage layout and responsive styles
- `src/index.css`: global styles
- `src/main.jsx`: React entry point
- `vite.config.js`: Vite React configuration

Product photos load from Unsplash, so internet access is needed for images. Cart and wishlist are frontend-only demos and are not connected to a backend, database, login, or payment gateway.
